## B. Onboard a new vendor & feed (UI)

Do this as **Onboarding** (or Priya in the local switcher), then approve as a **different** user (**Onboarding · Reviewer** / Dan).

| Step | Who | Action |
|------|-----|--------|
| 1 | Onboarding | **Vendors** → **Onboard vendor** → name (e.g. Harbor Lending) |
| 2 | Onboarding | **Add feed** → name + format (CSV / TXT / Excel) |
| 3 | Onboarding | Upload a sample tape for that feed (see §C / §D) |
| 4 | Onboarding | Review auto-mapping, transforms, DQ → **Submit for approval…** |
| 5 | Reviewer | **Approve…** / publish → signed Glue config badge appears |
| 6 | Monitoring | **File loads** / Import Monitor → **Upload file** to that feed |

Maker ≠ checker: the same person cannot approve their own mapping.

After publish, every boarding run uses the **signed** feed configuration only (drafts are never used by Glue).

## C. Samples for all four source **layouts**

Generated by `backend/lbp/samples.py` (default ~6% defects). Regenerate:

```bash
cd backend && .venv/bin/python -c "
from pathlib import Path
from lbp.samples import generate_all
print(generate_all(Path('../sample_data'), n=50))
"
```

| Type | Vendor (demo) | Format | File |
|------|---------------|--------|------|
| **PCG retail** | PennyMac Retail | CSV, camelCase, ISO dates, rates as % | `sample_data/pcg_retail_sample.csv` |
| **Bulk acquisition** | Atlas Capital | Excel, spaced headers, MM/DD/YYYY, rates as decimals | `sample_data/bulk_acquisition_sample.xlsx` |
| **Sub-servicing** | Cornerstone | Pipe TXT, cryptic codes, YYYYMMDD, amounts in **cents** | `sample_data/sub_servicing_sample.txt` |
| **Correspondent** | Summit / Westside | CSV, `LAST, FIRST` name, single-line address, `$` amounts | `sample_data/correspondent_sample.csv` |

**Positive-only (no injected defects):**

```bash
cd backend && .venv/bin/python -c "
from pathlib import Path
from lbp.samples import write_pcg_retail, write_bulk_excel, write_subservicing_txt, write_correspondent_csv
d = Path('../sample_data/positive')
d.mkdir(exist_ok=True)
write_pcg_retail(d/'pcg_positive.csv', 100, defect_rate=0)
write_bulk_excel(d/'bulk_positive.xlsx', 100, defect_rate=0)
write_subservicing_txt(d/'sub_positive.txt', 100, defect_rate=0)
write_correspondent_csv(d/'correspondent_positive.csv', 100, defect_rate=0)
print('wrote', d)
"
```

## E. Run a boarding job (once a feed is published)

### Local

1. **Monitoring** → File loads → **Upload file** → pick vendor/feed → choose sample  
2. Watch batch: pre-flight → micro-batches → reconcile  
3. **Loans to fix** for exceptions; **Monitor** for progress  

### AWS PoC

```bash
# Example: Correspondent-style CSV into the feed's source_id prefix
aws s3 cp sample_data/correspondent_sample.csv \
  s3://lbp-poc-raw-178137476317/incoming/<SOURCE_ID>/correspondent_sample.csv \
  --region ap-southeast-2

# Watch
aws stepfunctions list-executions \
  --state-machine-arn arn:aws:states:ap-southeast-2:178137476317:stateMachine:lbp-poc-boarding \
  --region ap-southeast-2 --max-results 5
```

Routing:

- Full CSV/TXT above `LBP_GLUE_THRESHOLD_ROWS` (PoC default **500 000**) → `lbp-poc-feed-spark` then `lbp-poc-feed-load`
- Smaller / Excel / change files → `lbp-poc-feed`
